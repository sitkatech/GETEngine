These are the files that should be present in each model

Baseline.dat                - the baseline streamflow output file 
Baseline.lst                - the baseline list output file
Baseline.hds                - the baseline heatmap data output file
AsrDataNameMap.csv          - the mapping between the budget data keys and the friendly names.  Also controls which data points get output.
SegRchZones.csv             - mapping for the zones to the segments/reaches
ZoneNames.csv               - Mapping of a zone to a friendly name
LocationFlowProportions.csv - Mapping a cannal to specified nodes or layer/row/col
LocationMapCoordinates.csv  - Mapping a node or layer/row/col to a set of lat/longs
